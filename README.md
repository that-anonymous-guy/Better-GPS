This is an abandoned project.

Basically, it adds a fully functionnal touch screen to any gps and phone and accessory to all displays on trucks, and road trip cars. This also adds custom made overlays, garmin, copilot, tomtom, kenworth, peterbilt, international, ford, you name it, all made by my hand, from scratch, to make it feel more authentic while driving trucks.

<img width="800" height="253" alt="kenworth-navplus-hd" src="https://github.com/user-attachments/assets/cbeff037-a366-430e-b2d6-35f6b72c1c27" />

Especially the T680 2022, it has an (almost) fully functional Kenworth NavPlusHD system. This was my most experimental base. I really wanted to make something good, that would have benefited the community, for free. And I feel bad about abandoning it.

Why? I am very good at texturing skills, creating art my way, but absolutely do not know how to code, so the implementation was made with AI. And it's not bad- I was very surprised what it could do. But that's... actually the issue. Not being made by a human. I decided I didn't want to use AI for this anymore.

If you don't care? Fine. Installation goes to: 

\American Truck Simulator\bin\win_x64\plugins

the dll and the folder goes there.
