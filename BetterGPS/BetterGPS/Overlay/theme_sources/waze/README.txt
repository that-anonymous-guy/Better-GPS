[blue]Waze Navigation[normal]
This mod brings a fresh look to your cabin GPS. It turns the boring default map screen into Waze style to make the navigation more realistic.


[orange]Features[normal]
- Cabin GPS with Waze interface style.
- Map icons inspired on Waze reports style.
- Road marker icons (job start/target).
- Navigation path, roads and background colors like Waze.
- Speedometer.
- Shows remaining travel time (in-game time).
- Shows cruise control speed (when activated).
- Switch to the dark theme when headlights are turned on.


[orange]Important[normal]
- If the icons/colors are not applied maybe it's due to a mod conflict. Try to set this mod to higher priority.
- In some cabs the map is too bright/dark, you can change the brightness by using the dashboard backlight setting.
- The background color an the interface design for now are applied only vanilla in-vehicle navigation screens and cab accessories (DLC). There's a default design that may be compatible with mod trucks.
